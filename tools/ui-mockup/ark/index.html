FRAMEFILM // ARK THEME // DESIGN DRAFT 03

终末地视觉语言 · 设计稿 03

上一版虽然调成了白底墨字，但造型语言没换 —— 满屏 1px 方框，确实生硬。这一版按官网真正的做法重做： 黄是「块」不是「线」（黄横幅 / 黄方块按钮 / 黄竖标 / 黄三角子弹）、数据用黑 chip、 形状要杂（圆 + 药丸 + 方块 + 横幅混用）、技术装饰（▌段头 / 标尺刻度 / HUD 圆环 / CMYK 色标 / 网点底纹）。 不是给老界面换皮，是换成官网那套构图与节奏。

05 加载屏 · 连接 ARK 后的过渡

切换流程

步骤行为
① 默认打开 ForFilm = 现有「贴纸玩具」界面，无变化
② 判定BLE 广播名 FRAMEFILMARK → 判定 ARK（复用 js/utils.js）
③ 遮屏叠加加载屏，同时给 <body> 加 .theme-ark
④ 推进进度三段加权：主题资源 → 设备信息(0x42) → 首帧渲染
⑤ 擦除终末地黄自左向右铺满（0.6s），再延迟 1.4s 淡出
⑥ 落屏露出白底墨字界面
断开反向擦除 → 移除 .theme-ark → 回「贴纸玩具」
规格逐条对映官网 __00-Loading_*：竖条 20px、读数 left:50px/bottom:26px（本稿 76/30）、数字 70px、短棒 8×30 r4、黄幕 scaleX 0→1 .6s cubic-bezier(1,0,.7,1)。

06 落地策略

问题做法
适用范围仅 ARK（FRAMEFILMARK）；Pro / Max / STD / Dock 完全不变
默认不变打开仍是现有界面；连上 ARK 才播加载屏并切换，断开回退
响应式沿用现有 900px 断点与栅格，只换视觉、不动结构
如何启用新增 css/ark-theme.css，规则挂 .theme-ark；连接成功给 <body> 加类，不改现有 style.css
改动范围纯 CSS 覆盖 + 加载屏组件 + 少量类名钩子；不动 JS 业务逻辑与 BLE 常量
新增图形黄三角子弹 / 菱形标 / CMYK 色标 / HUD 环 / 标尺 —— 全部 CSS + 内联 SVG 实现，无额外图片依赖
字体Chakra Petch / Barlow / JetBrains Mono，仅 ARK 连接后按需加载，计入进度
